# US-Address-Data-Cleaner
I created this project to demonstrate how Python automation can replace manual data entry tasks in financial and tax-related workflows.
My Solution: I developed a custom Python script using the Pandas library. The tool automatically parses address strings, extracts state information, and standardizes it to ISO formats.

The Result: > - 100% accuracy in state verification.

    Processing time reduced from hours to mere seconds.

    Automated audit trail for tax compliance.
